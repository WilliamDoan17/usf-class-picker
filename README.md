# USF Class Picker

## About

USF Class Picker is a tool for getting class information, confirm auto track and notify the user whenever the wanted class has a slot.

How to use:

1. Search for the class by its criteria (Semester, CRN, Subject Number, Title, Professor, Number of Credits)
2. View results of the search and choose the target class with suitable time and professor
3. The app will auto track and poll every 1 hour, notifying the user whenever the class is available
